# QuizApp — Веб-приложение для проведения квизов в реальном времени

Студенческий проект: платформа для создания и проведения интерактивных квизов
по аналогии с Kahoot.

## Возможности

- ✅ Регистрация и авторизация (участники и организаторы)
- ✅ Создание квизов с вопросами разных типов (одиночный/множественный выбор)
- ✅ Поддержка изображений в вопросах
- ✅ Настройка времени на каждый вопрос
- ✅ Запуск квиза с генерацией 6-значного кода комнаты
- ✅ Подключение участников в реальном времени через Socket.io
- ✅ Синхронная демонстрация вопросов всем участникам
- ✅ Подсчёт баллов (быстрее ответ = больше очков)
- ✅ Лидерборд после каждого вопроса и финальный
- ✅ Личный кабинет с историей проведения/участия
- ✅ Сохранение всех данных в SQLite

## 🛠 Технологии

- **Backend:** Node.js, Express, Socket.io
- **База данных:** SQLite (better-sqlite3)
- **Аутентификация:** express-session + bcrypt
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Загрузка файлов:** multer
